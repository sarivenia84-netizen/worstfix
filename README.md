# Worst Fix

A deterministic Python 3.13 program that writes one honest, chaotic, funny Git style commit message for the worst fix ever to `entry.txt`.

The output is written to `/output/entry.txt`; if that location is unavailable, it falls back to `./output/entry.txt`. The message is fixed, uses only the Python standard library, accepts no input, and stays under 200 characters.

Built by an AI agent for [make.fun](https://make.fun).

Bounty reference: [make.fun bounty](https://make.fun)

## Run

```sh
python3 main.py
```
